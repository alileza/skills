A skeptical audit, on real data

Do token-reduction skills actually save money?

This repo ships two Claude Code skills that promise to cut token usage. Before believing that, we audited one real account — every number on this page comes from its own ccusage exports and raw session transcripts, not from vendor benchmarks. The honest answer: the skills route you to the right fix, but the fixes that guarantee savings live outside the skill system.

01 · Where the money goes

Cost ≈ context size × turns

Every turn re-sends the full accumulated conversation as input. So the bill is dominated not by what Claude writes, but by what the context has accumulated — re-billed on every subsequent turn. The composition bar makes this stark: fresh input and output are rounding errors.

02 · The dominant pathology

One session ran for 24 days

The largest transcript on the account is 57 MB: a single session from June 26 to July 20 — 487 user turns, 1,491 shell commands, 1,374 edits, 812 file reads, all sharing one ever-growing context. By the end, every small question re-billed weeks of accumulated history. Session length, not any single expensive operation, is the account's number-one cost driver.

03 · Claims vs reality

The gap between headlines and measurements

Code-graph tools advertise 49–70× reductions (≈98% fewer tokens). The only independent measurements we could find land in single digits. And on this account the premise fails outright: 93% of reads were already scoped with offset/limit before any skill or tool was installed — there was almost no exploration bloat for an index to remove.

Claimed vs independently measured token reduction

Vendor / blog claim Independent measurement
“49×” and “70×” convert to ≈98% and ≈98.6% reduction. JetBrains: 8.5% across 86 real tasks. Combined replay of three reduction tools over a 614M-token corpus: 3.7%. Repo-dependence is real — but a 12–26× gap between claim and measurement is the pattern, not the exception.

The uncomfortable summary: if you installed the two skills and nothing else, expect single-digit-percent savings — consistent with every independent measurement. If you keep the habits they point at (clear at boundaries, keep files small, keep images out of long sessions) and delete the skills, you keep most of the value. Install them for the guided path to that state — not because installation itself saves tokens. Measure your own before/after with ccusage; believe nothing else, including this page.
